### 阶段 4：AI 层（第一阶段之后）

**目标目录**：`src/xianwen/ai/`

建议结构（实现时可微调）：

```text
src/xianwen/ai/
├── __init__.py
├── models.py          # 请求/响应/校验 schema
├── provider.py        # 主模型预设与白名单
├── client.py          # httpx 调用、超时
├── validate.py        # 输出校验
├── fallback.py        # 后备文本路径
├── budget.py          # token / 调用次数预算
└── mock.py            # 本地固定响应
```

#### 产品约束（必须写进实现与测试）

| 项 | 要求 |
| --- | --- |
| 主模型 | DeepSeek / 千问 / 智谱 GLM 实测后**只选一个**；其余延期 |
| 白名单 | 仅允许服务端预设 + 有限模型列表；禁自定义 URL / 自由模型名 |
| 调用时机 | 选前扩写最多 1 次/回合；终局人物志可额外 1 次；选后不调 AI |
| 失败 | 格式/越权/错种子 → 重试 1 次 → 仍失败用种子后备文本 |
| 自动后备 | 无 Key、网络失败、服务错误、预算耗尽 → 后备模式 |
| 预算 | 默认 60k token；80% 提示；100% 切后备；每局 ≤ 25 次调用（含重试与终局） |
| Key | 页面内存 → 服务端即时转发；不写存档/日志/URL；错误不回显完整 Key |
| 输出校验 | 种子 ID ∈ 候选；选项 ID 完全一致；每选项有结果文本；无状态修改指令 |

#### 必写测试

- 合法 AI 响应通过校验并返回扩写文本。
- 非法响应触发重试；二次失败走后备。
- 超时 / 网络错误走后备。
- 无 Key 完整可玩路径。
- Mock 路径下 CI 零外网。
- Key 脱敏：日志与错误信息无完整 Key。
- 预算达 100% 自动后备；调用次数上限生效。
- 未启用预设返回明确错误。

#### 与 D 的接口约定（实现前对齐）

- 场景请求：状态摘要 + 候选事件 +（可选）临时 Key + 锁定的服务/模型。
- 响应：校验后的场景/选项/结果文本，或后备文本 +「已使用后备」提示字段。
- 选择请求：不再要求 Key。
- 局内锁定服务与模型；允许重输 Key，禁止中途换模型。
